# Раскладчик — контекст для нового чата

Передаточная записка: что за программа, как мы работаем, где что лежит и на чём остановились (ноябрь 2026, версия 1.4.17).
Подробное устройство кода — в `docs/DEV.md` (в проекте — `claude/README_исходники.md`).

## Что это

**Раскладчик** — программа для Windows для металлоцеха: длина реза, раскладка деталей по хлыстам/листам с минимумом отходов, закупка металла и файлы для станка.
- Внутри — HTML/JS-страница, её показывает Edge в режиме приложения (`--app`), рядом — маленький запускатель на Go (локальный сервер `127.0.0.1:47817`, только этот ПК). В обычном браузере открывается по адресу `http://127.0.0.1:47817/`, пока программа запущена (с «localhost» не пустит).
- Разделы: **Трубы** (x_t / IGES / STEP / PDF / TIF / вручную → рез, раскладка по хлыстам, закупка, «Раскрой трубы ТЕСТ» → .igs на хлыст → .zzx через TubesT), **Лист** (DXF: проверка, исправление, редактор, раскладка на листе), **Редактирование PDF** (закраска организаций/печатей/фамилий).
- Проект — один файл `.dsmet` (хранит только пути к файлам, не копии).

## Где код

- GitHub: `prostmakar/raskladchik` (публичный), ветка `main`.
- Сборка: `python3 build.py` (страница + exe, Go 1.24+), `python3 build.py --no-exe` — только страница. Тесты: `node tests/test_*.js` (calc, dxf, iges, step2iges, tubecut, xt).
- Выпуск: GitHub Actions собирает релиз, когда меняется `VERSION` (+ `notes/vX.Y.Z.md`). Пуш в `main` без смены `VERSION` релиз не делает. Программа сама предлагает обновиться.
- Коммиты: `git -c user.name=prostmakar -c user.email=prostmakar@users.noreply.github.com commit`, названия в духе «… — крутые правки».

## Правила работы (важно)

- Отвечать по-русски, коротко и по делу; сначала отвечать на вопросы, потом что-то запускать.
- **Версию не выпускать без команды.** Порядок: показать описание обновления → пользователь правит → «выпускаем» → выпуск. Номера `1.4.x`; `1.5` — только по слову пользователя (1.5 = стоимость резки, КП).
- Описания и надписи в программе — короткие, голосом пользователя, без пояснительных текстов. Надписи в интерфейсе не менять без нужды («→ .zzx», «Перевести в .zzx», «TubesT: N из M — не трогайте мышь и клавиатуру» — так понятнее обычному пользователю).
- Исходные файлы пользователя не трогать; сохранять в выбранную пользователем папку; в папке раскроя — только .igs/.zzx (никакого «Раскрой.txt»).
- TubesT — строго по одному файлу за раз (ПК слабый). .zzx сохраняется в ту же новую папку раскроя рядом со своим .igs. .zzx открываются в **TubePro** (TubesT только делает их).
- На ПК пользователя без спроса ничего не нажимать в его окнах; клавиши в TubesT уходят только когда она активна. Если пользователь занят (игра, работа) — не запускать проверки, всплывающие поверх.
- Почта пользователя — приватная, никуда не отправлять.

## Последние версии

- **1.4.15** — STEP тоже в .zzx, TubesT сохраняет сама.
- **1.4.16** — IGES считаются правильно (файлы Open CASCADE: склейка общих рёбер), .zzx по кнопке «Перевести в .zzx» (не сам), «Рез на 1 шт» в метрах (клик по заголовку → мм).
- **1.4.17** — STEP переводится через Mayo (открытый конвертер на ядре Open CASCADE). Скачивается сам при первом раскрое со STEP (~45 МБ, сверка SHA-256) в `%LOCALAPPDATA%\Раскладчик\mayo`. Каждая деталь после перевода сверяется с исходным STEP; если Mayo недоступен — запасной свой переводчик и строка «STEP через запасной переводчик (проверьте в TubesT)».

## Что выяснили про TubesT (важно для будущих правок)

- TubesT Lite 7.1.27.1: `C:\Program Files (x86)\Friendess\TubesTLite\TubesTLite.exe`, читает только IGES. TubePro: `C:\Program Files (x86)\Friendess\TubePro\TubePro.exe`.
- Профиль хлыста TubesT определяет по любой «понятной» детали в файле. Уголок 746113.040/043 (полка подрезана ступенькой 22 мм на торцах) **один в файле не открывается ни с каким переводчиком** — хлыст только из таких деталей TubesT не откроет. Вместе с обычными деталями — открывается.
- Свой переводчик STEP→IGES ломал детали с отверстиями (039-01) — поэтому перешли на Mayo. Проверено на заказе уголков 25×25×3 (8 видов STEP): 7 хлыстов открылись в TubesT, .zzx сделаны (~18 с на хлыст, 57 деталей — 73 с), открываются в TubePro.
- Компас-3D v24 на ПК пользователя умеет переводить STEP→IGES через COM (VBScript: `Kompas.Application.5`, `Document3D.Open`, `AdditionFormatParam.format=4`, `SaveAsToAdditionFormat`; из PowerShell API5 не работает). Хлыст из файлов Компаса открылся с неверной длиной — скорее наша недоработка сборки, не разобрано. Отложено.

## Открытые вопросы / идеи

- Предупреждать, если хлыст состоит только из деталей, которые TubesT не распознаёт (как 040/043), или подмешивать в такой хлыст обычную деталь того же профиля.
- x_t в раскрое — отложено пользователем («пока x_t оставим»).
- Версия 1.5 — стоимость резки, КП (только по команде).
- Внимательно следить за подсчётом IGES из разных САПР (пользователь просил «нужно будет внимательно еще следить»).
