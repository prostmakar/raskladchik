# Раскладчик

Программа для лазерной резки. Считает, раскладывает, чистит чертежи.

- **Трубы** — длина реза, врезки, раскладка по хлыстам
- **Лист** — проверка DXF, раскладка на листе
- **PDF** — убрать организации, печати, фамилии
